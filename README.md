# PresenceGuard

An unofficial Vencord userplugin for local own-status observation and optional
GNOME display-idle and webcam Do Not Disturb rules. Observation is the initial
installation mode; automation is opt-in and protects manual status choices.

Implementation and verification are in progress on the feature branch.

Licensed under GPL-3.0-or-later. Not approved by Discord; compatibility is not
guaranteed. No backend, telemetry, or media capture.
